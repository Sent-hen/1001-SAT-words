# TASK: Three images per frame (Story Panel · Memory Card · Route Map)

> **For Claude Code.** Read this file fully before you touch any code. Work on a new git branch called `three-images`, and commit in small steps.

## 0. Goal in one paragraph

Each chapter page of *The Thousand and One Words* has 10 frames, one per SAT word. Each frame should show **three separate images** instead of one, each serving one memory method:

| # | Image | Method | Job |
|---|---|---|---|
| 1 | **Story Panel** | Story | The comic scene: characters, dialogue, the word used in context. **This already exists; keep it.** |
| 2 | **Memory Card** | Link (+ loci station) | The absurd OAES image that links word *k* to word *k+1*, drawn **sitting on the loci station** (Arch, Step, Lamp…). It is visibly "dream-styled" so kids know it's the memory trick, not the plot. |
| 3 | **Route Map** | Loci (city scale) | A crop of the city map with a "**YOU ARE HERE**" marker at the current landmark and station, and a **dotted line to the next stop on the route**, like an airport wayfinding map. The colors contrast with the original map. |

The Memory Card and the Route Map must be **independent of each other**. They are generated by separate modules, rendered as separate `<svg>` elements, share no state, and each can be hidden or shown on its own. Never merge them into a single image.

5. Build with **one command**, `python3 src/build_text.py`, which regenerates all 100 pages.

## 3. Image 2: the Memory Card (`src/memcard.py`, new)

### 3.1 What it shows
One absurd image that combines **word k's object** and **word k+1's object** in an OAES interaction, **placed on the station of word k**. It's drawn from the frame's existing `L:` (link) and `C:` (loci) lines.

Example, Chapter 1, Frame 1 (anomaly→ominous, station ARCH): a crescent-shaped arch. In the keystone sits a *giant lying garden gnome* wearing the green moon as a hat, and mean black crows burst out of his open mouth.

### 3.2 Look and feel (must contrast with the Story Panel)
- **Size:** `viewBox="0 0 300 300"` (square). Frame 0 uses the same size, not wide.
- **Dream style:** a soft radial gradient background (`#2a1450` → `#6b2fa0`, with a faint pink `#ff9fc4` glow at the center), a **double gold border** (`#f4c542` outer 6px, `#fff6c9` inner 2px) with rounded corners, and a slight "sparkle" layer (reuse `sparkle()`).
- **Station stage:** the bottom 40% shows the **station template** for station k, drawn **the same way on every card of every chapter**. For example, every ARCH card has the same arch shape and every LAMP card has the same hanging lamp, re-tinted with that chapter's district color from `citymap.DISTRICTS`. This consistency is what makes loci work. Put the templates in `station_stage(k, tint)`, one function per station.
- **Link objects:** Object A (word k) and Object B (word k+1) sit on or around the station, with a thick curved **arrow** from A to B (`#ff2d95`, 5px) to show the link direction.
- **Labels, at the top:** `WORD k → WORD k+1` in Bangers, white with an INK stroke. At the bottom-left, a station badge (e.g. `① ARCH`).
- **OAES chips,** at the bottom-right: four small circles labeled O, A, E, S. Light up in gold only the ones used by this link. Detect them from the `L:` text, which already contains "(Out of proportion…)", "Action", "Exaggeration", "Substitution".

### 3.3 Data: add structured card specs (new file, do not edit `content/`)
Create `content/cards/cards_001-010.txt`, … (one file per 10 chapters) with **one line per frame**:

```
## 1
1 | A: gnome(lying, green-moon hat) | B: crows(mean, many) | ACT: bursts-out-of-mouth | SCALE: A=giant | OAES: O,A,S
2 | A: crows(mean) | B: imp(red, riding crow) | ACT: rides-like-rocket | SCALE: - | OAES: A,E
...
```

- Author Chapter 1 carefully by hand, reading its `L:` lines.
- For chapters 2–100, write a helper `tools/draft_cards.py` that drafts these lines from each frame's `L:` and `H:` text. The capitalized substitution noun in `L:` is usually object B (e.g. "a giant TICK", "the MEAN crows"). Then **review and fix the drafts by hand in batches of 10 chapters**. Don't ship un-reviewed drafts silently. Report which chapters were reviewed.
- Extend `content.py` with `parse_cards()`. If a frame has no card line, `memcard.py` falls back to a generic card: the station stage + a glowing spark + the two words + an arrow.

### 3.4 Object library
Create `src/objects.py`: small drawing functions keyed by noun (e.g. `gnome`, `crow`, `imp`, `tick`, `candy`, `pickle`, `ball`, `fish`, `bull`, `parrot`, `robot`, `cat`, `whale`, `egg`, `crown`, `bell`, `ant`, `bee`, `dragon`, `train`, `cake` …), each taking `(x, y, scale, mods)`.
- Reuse shapes from `art.py`, `props.py` and `ch001.py` (`crow`) where possible.
- Unknown nouns fall back to a labeled "thought bubble" with the noun written inside, so nothing ever crashes.
- Start with the ~40 nouns used in chapters 1–10, then grow the library. Keep a coverage report (`tools/card_coverage.py`) that lists the nouns still using the fallback.

## 4. Image 3: the Route Map (`src/routemap.py`, new)

### 4.1 What it shows
A **cropped, re-colored view of the city map** centered on the current landmark, with airport-style wayfinding:

- **YOU ARE HERE:** a large pin at the current chapter's landmark (`data/map_points.json`). It has a pulsing ring (a CSS animation on a `<circle>`, respecting `prefers-reduced-motion`) and a label pill reading `YOU ARE HERE · Ch.N <landmark>`.
- **Dotted line to the next stop:** a bold dashed path (`stroke-dasharray="10 8"`, round caps) from the current landmark to the **next landmark on the route** (chapter N+1), ending in an arrowhead and a small label `NEXT: Ch.N+1 <landmark>`. On Frame 0 (i=9) this leg is **emphasized**: thicker, full opacity, with a "→ next chapter" tag. On frames 1–9 it's drawn at 50% opacity. Chapter 100's next stop is chapter 1, where the loop closes.
- **Journey so far:** route points 1…N-1 drawn as small filled dots joined by a solid line (the "traveled" path). Points after N+1 are hollow, faint, dotted.
- **Station strip (inside the same map image):** along the bottom, a mini strip of the 10 stations of this landmark (A S L R H P W S B T). The current station (index i) is highlighted with the same pin color, earlier stations are filled and later ones hollow, and a **dotted line runs to the next station**. On Frame 0 the dotted line runs off the strip's right edge toward the next landmark. This is the "you are here" inside the building, while the big map is the "you are here" in the city.

### 4.2 Colors (must contrast with the original parchment map)
Render the base map **desaturated and cool**:
- Wrap the base map in a group with an SVG `filter` (`feColorMatrix type="saturate" values="0.15"`), plus a `#0f1d2e` overlay at ~55% opacity, giving a dark "night-mode" wayfinding look.
- Overlay colors, using CSS custom properties so they are easy to retune:
  - `--here: #ff2d95` (hot magenta): the pin, pulse and current station
  - `--next: #00e5ff` (cyan): the dotted next leg and the NEXT label
  - `--traveled: #9cff57` (lime): the traveled path and past dots
  - `--future: #8a94a6`: future dots, dotted and faint
  - Labels are white text with a dark `#0f1d2e` pill background.
- Check contrast: the pin and labels need at least **4.5:1** against the darkened map. Verify this programmatically and print the ratios.

### 4.3 Implementation notes
- **Don't parse `images/city_map.svg` at build time.** Refactor `src/citymap.py` so a function returns the base-map SVG *body* (no outer `<svg>`), and namespace any IDs it defines (e.g. the `sand` pattern → `cm-sand`).
- **File size:** put the base map **once per page** in a hidden `<svg style="display:none"><defs><symbol id="cm-base" viewBox="0 0 1500 1160">…</symbol></defs></svg>`. Each Route Map is then a small `<svg viewBox="0 0 300 300">` that contains a nested `<svg x=0 y=0 width=300 height=240 viewBox="{crop}">` holding `<use href="#cm-base"/>` plus the overlays. The station strip sits in the bottom 60px.
- **Crop:** a 520×416 window in map coordinates centered between the current and next landmark, clamped to the map bounds. Make sure both points are inside the crop with at least 40px of margin. If they aren't, grow the window.
- The map must also be readable **standalone**: add a `<title>` and `<desc>` (e.g. "Chapter 7, Pearl Divers' Pier, station 3 Lamp. Next: Spice Warehouses").
